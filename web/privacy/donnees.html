Procédure de suppression · 23 octobre 2026

Depuis Hamigo

  1. Ouvre Moi → Paramètres → Mes données.
  2. Choisis Supprimer mes données sur GitHub et lis la confirmation.
  3. Confirme la suppression. Hamigo suspend les publications, supprime ses Gists sur ton compte puis se déconnecte. Ta progression et tes réglages restent sur ce téléphone.

Si une interruption empêche de terminer, la synchronisation reste suspendue et tu peux réessayer. Si un Gist contient aussi des fichiers étrangers à Hamigo, l’app refuse de le supprimer pour les préserver ; utilise alors la procédure manuelle ci-dessous.

Sans réinstaller l’app

  1. Déconnecte Hamigo sur tes autres appareils, ou révoque son autorisation dans les applications autorisées de GitHub. Cette révocation arrête les futurs accès mais ne supprime pas les Gists.
  2. Connecte-toi au compte utilisé par Hamigo et ouvre tes Gists sur GitHub.
  3. Retrouve les Gists Hamigo : leur description indique la sauvegarde complète ou les statistiques. La sauvegarde contient hamigo-backup.json et éventuellement des fichiers hamigo-device-…json ; le résumé social contient hamigo-progress.json.
  4. Pour chaque Gist Hamigo à effacer, utilise Delete puis confirme sur GitHub. Supprime le Gist entier pour effacer également son historique ; vider seulement un fichier ne suffit pas. Vérifie auparavant qu’il ne contient pas d’autres fichiers à conserver.

Cette opération concerne tes données Hamigo. Tu n’as pas besoin de supprimer ton compte GitHub.

Autres données et limites

Pour les commentaires de demandes d’amis déjà publiés sur les Gists d’autres personnes, ouvre ces Gists et supprime tes commentaires depuis GitHub. Les copies indépendantes déjà exportées, capturées ou reçues par des équipiers ne peuvent pas être effacées à distance par Hamigo.

Les données locales disparaissent si tu effaces volontairement les données Android de Hamigo ou désinstalles l’app. Une sauvegarde sur GitHub est indépendante : supprimer l’app ne supprime pas les Gists et supprimer les Gists ne supprime pas la progression locale.

Pour demander la suppression d’un message ou de fichiers envoyés au support, utilise le formulaire de contact Hamigo. Indique les éléments permettant de retrouver le retour, sans transmettre de jeton ou de mot de passe. Le support accuse réception et traite les demandes de droits dans les délais applicables, en principe un mois.

L’éditeur n’a pas d’accès administrateur à ton compte GitHub : il ne peut pas supprimer tes Gists à ta place depuis un serveur Hamigo. La procédure ci-dessus permet de les supprimer directement depuis ton compte, sans l’app.
