Hamigo 1.0 prépare l'arrivée sur Google Play avec une identité de version stable et la continuité des mises à jour depuis les APK précédents.

Le parcours, les fiches mémo, les examens, l'équipe et l'accès de démonstration examinateur reprennent la RC 0.56 validée. Les historiques de série déjà enregistrés sont conservés ; l'ancienne migration temporaire de série est retirée.

La version produit est indépendante des commits de développement. Les alphas correspondent aux tests internes, les bêtas aux tests ouverts ; chaque bundle possède un numéro technique unique. Les sources et vérifications sont disponibles dans le dépôt.
